# Portfolio Compliance Checker Project Brief

## Core Objective
Build a Python-based Portfolio Compliance Checker that evaluates investment portfolios against regulatory and internal policy rules, and generates clear pass/fail results for each position.

## Key Features
1. Rule Engine: Define and evaluate compliance rules such as concentration limits, prohibited asset classes, and position size thresholds.
2. Portfolio Ingestion: Load portfolio holdings from CSV or JSON input and normalize them for rule evaluation.
3. Compliance Reporting: Produce a summary report with compliance status, rule violations, and actionable findings.

## Tech Constraints
- Python
- SQLite

## Definition of Done
- A Python solution processes portfolio data and applies compliance rules.
- Inputs can be ingested from CSV or JSON files.
- Outputs include a compliance summary and identified rule breaches.
- Data can be stored or audited in SQLite for traceability.
